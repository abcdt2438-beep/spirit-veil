# VEIL CIRCLE

Real-time spirit channeling web app: live camera, occult HUD, and AI-flavored chat across the veil.

## Use it

Open `index.html` over HTTPS (or localhost). Tap **open eye** to allow the camera. Choose a voice. Speak.

This first build uses local atmospheric replies so it works with zero API keys. Plug a chat API into `app.js` later if you want a live model.

## Stack

Static HTML / CSS / JS. Camera via `getUserMedia`. No backend.
